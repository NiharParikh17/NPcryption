NPcryption

An educational, pure-Python RSA encryption and decryption library with an interactive CLI.

Coming soon: an interactive demo that runs NPcryption in your browser and shows each step of key setup, encryption and decryption.

What it shows

How RSA works under the hood: square-and-multiply modular exponentiation, and deriving the private key with the Extended Euclidean Algorithm. It has no third-party dependencies and is meant for learning, not for protecting real data.

Try it

pip install "git+https://github.com/NiharParikh17/NPcryption.git"
>>> from npcryption import encrypt, decrypt
>>> encrypt(17, 19, 5, "Hello")
'021271109109042'
>>> decrypt(17, 19, 5, "021271109109042")
'Hello'
